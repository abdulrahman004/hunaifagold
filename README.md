# Hunaifa's Gold

A single-screen gold coin tracker for GitHub Pages. The default coin is 2 g of 22K gold purchased in Hyderabad on August 7, 2026.

The purchase total was ₹29,100, including charges and GST. The purchase date USD/INR reference rate was 95.15, making the original dollar cost about $305.83. The estimate is the latest published India benchmark for the selected karat multiplied by the coin's weight. It is indicative, not a jeweller's buyback offer. Today's USD value uses the latest USD/INR reference rate. Dollar change compares today's converted value with the original dollar cost.

The gear opens editing for the coin details and an optional local Hyderabad or Malabar rate. Changes are saved only in that browser's local storage. Data sources: [snapdata's daily India gold dataset](https://snapdata.dev/docs/) (IBJA benchmark with attribution) and [Frankfurter reference FX rates](https://frankfurter.dev/). The receipt is intentionally not included in the repository or published site.

To preview locally, run `python3 -m http.server 8000` here and open `http://localhost:8000`.
