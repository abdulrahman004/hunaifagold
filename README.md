# Hunaifa's Gold

A small static website that estimates the value of a 2 g, 22K gold coin purchased in Hyderabad on August 7, 2026.

The purchase total was ₹29,100, including charges and GST. The purchase date USD/INR reference rate was 95.15, making the original dollar cost about $305.83. The estimate is the latest published 22K India benchmark per gram multiplied by 2 grams. It is an indicative Hyderabad value, not a jeweller's buyback offer. Visitors may enter a local 22K quote instead. Today's USD value uses the latest published USD/INR reference rate. Dollar profit compares today's converted value with the original dollar cost.

Data sources: [snapdata's daily India gold dataset](https://snapdata.dev/docs/) (IBJA benchmark with attribution) and [Frankfurter reference FX rates](https://frankfurter.dev/). The original receipt is intentionally not included in the repository or published site.

To preview locally, run `python3 -m http.server 8000` here and open `http://localhost:8000`.
